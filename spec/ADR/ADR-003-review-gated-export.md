# ADR-003 — Exportação controlada por Review Wizard

| Campo                   | Valor                                         |
| ----------------------- | --------------------------------------------- |
| Status                  | Aceito                                        |
| Contexto                | Timing automático pode gerar erro perceptual. |
| Decisão                 | Download final passa por export gate.         |
| Consequências positivas | Reduz exports ruins e preserva audit trail.   |
| Consequências negativas | Adiciona etapa extra antes do download.       |
