# ADR-007 — Correções agressivas viram candidate take

| Campo                   | Valor                                                                |
| ----------------------- | -------------------------------------------------------------------- |
| Status                  | Aceito                                                               |
| Contexto                | Timing automático pode alterar intenção vocal.                       |
| Decisão                 | Correções arriscadas não sobrescrevem take aprovado silenciosamente. |
| Consequências positivas | Mais segurança editorial.                                            |
| Consequências negativas | Review Wizard precisa lidar com múltiplos takes.                     |
